# MovieNova (with Cast button)

Upload ALL files in this folder to the root of a GitHub repo.
The build file is in `.github/workflows/build-apk.yml`.
If the hidden `.github` folder does not upload, create it on GitHub with
Add file > Create new file, name `.github/workflows/build-apk.yml`, and paste the
contents of `build-apk.yml.txt` (visible copy in this folder).
Then Actions > Build APK > Run workflow, and download the APK from Artifacts.
